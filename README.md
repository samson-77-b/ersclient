# ERS Digital Twin — Frontend Client

Interactive 3D Digital Twin Studio for the in-vehicle Emergency Response System (ERS).

## 🚀 Getting Started

### Install Dependencies
```bash
npm install
```

### Run Locally (Development)
```bash
npm run dev
```

### Build for Production
```bash
npm run build
```

## 🌐 Deploy to Vercel
This repository is pre-configured for instant zero-configuration deployment to [Vercel](https://vercel.com):
- Framework Preset: **Vite**
- Build Command: `npm run build`
- Output Directory: `dist`
